# Real Jaeger trace evidence

The recorded trace was generated by a **real loopback HTTP POST** to a small synthetic Fastify route using the shipping compiled SpaceApp API observability hooks and trace-context code. The request starts the shipping `codexAppServerTurnWorkflow` on a real Temporal test server. One Temporal `Worker` runs that workflow and a stub `runCodexAppServerTurn` activity, which returns a completed result without calling a provider.

Both shipping exporters sent OTLP/HTTP directly to a real **Jaeger 2.22.0** collector. [jaeger-trace.json](jaeger-trace.json) is the **unchanged response** from the local Jaeger query service at `/api/traces/{traceId}`. It can be imported through the official Jaeger demo UI's Upload control. The trace was recorded locally, independently of the public demo backend.

## Reproduce

Use the supported Node 22 runtime, an unprivileged development user and official Jaeger 2.22.0. Check out and build the exact public solution:

```sh
git clone https://github.com/Arnavquartz/spaceapp.git
cd spaceapp
git checkout 089527f10f7bc3b8c2b38c7ca72a4d0094260edb
ELECTRON_SKIP_BINARY_DOWNLOAD=1 npm ci
npm run build
```

Start Jaeger with the supplied configuration. It listens only on loopback and keeps at most 100 traces in memory:

```sh
jaeger --config /absolute/path/to/jaeger.yaml
```

Keep Jaeger running and execute the supplied scripts from another terminal:

```sh
node /absolute/path/to/generate-trace.cjs /absolute/path/to/spaceapp /absolute/output/dir
node /absolute/path/to/export-trace.cjs /absolute/output/dir
```

Each run creates new identifiers and timestamps. The export script checks the connected API → workflow → activity chain and the absence of the synthetic prompt and provider output, then saves the unmodified Jaeger response and verification summary.

Open the local Jaeger UI at `http://127.0.0.1:16686` and look up the new trace ID from `run.json`. Alternatively, use **Search → Upload** in the [official demo UI](https://jaeger.demo.jaegertracing.io/) and select the generated `jaeger-trace.json` file. The public demo's trace URL alone will not reproduce imported browser-local data.

Official [Jaeger 2.22 API documentation](https://www.jaegertracing.io/docs/2.22/architecture/apis/).
